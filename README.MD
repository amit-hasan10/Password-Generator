
# Secure Password Generator

A simple and secure password generator built using Python.

## About the Project

This project generates random and secure passwords based on user preferences.

Users can specify the password length and choose whether to include numbers and special symbols.

## Features

- Generate secure random passwords.
- Customize password length.
- Include or exclude numbers.
- Include or exclude special symbols.
- Always includes uppercase and lowercase letters.
- Uses Python's secrets module for secure randomness.

## Technologies Used

- Python
- String Module
- Secrets Module

## How to Run

1. Clone this repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:

   cd Password-Generator

3. Run the Python file:

   python password_generator.py

## Example

Enter password length: 12
Include numbers? (y/n): y
Include symbols? (y/n): y

Your generated password is:
Example@123Ab
